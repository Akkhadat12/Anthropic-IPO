# วิธีเปิด Anthropic IPO บนเครื่องของคุณ

> สถานะรุ่นนี้: PROVISIONAL_RUNTIME_NOT_VERIFIED — เป็นแพ็กเกจชั่วคราว ยังไม่ยืนยันการแสดงผล Webapp จาก ZIP ที่ส่งจริง และยังไม่ผ่านการตรวจรับอิสระ ผลทดสอบ START.bat/STOP.bat บน Windows = NOT_RUN (ยังไม่ได้รันบน Windows จริง) การทดสอบ helper บน Linux ผ่านแล้ว แต่ไม่ใช้แทนการตรวจภาพ/เบราว์เซอร์หรือ Windows

## เตรียมครั้งเดียว

- ใช้ Windows พร้อมเบราว์เซอร์ Chrome หรือ Edge รุ่นปัจจุบัน (วางแผน Chromium 140 ขึ้นไป; ยังไม่รับรองผลทดสอบเบราว์เซอร์) และ Python 3.10 ขึ้นไป
- ถ้ายังไม่มี Python ให้ติดตั้งจาก https://www.python.org/downloads/windows/ โดยเลือก Python launcher หรือเพิ่ม Python ลง PATH
- แพ็กเกจนี้ไม่ได้รวม Python และไม่ติดตั้งโปรแกรมหรือดาวน์โหลดส่วนประกอบให้อัตโนมัติ
- เมื่อเตรียม Python แล้ว การเปิดใช้งานปกติไม่ต้องมีอินเทอร์เน็ต ไม่ต้องใช้ npm ไม่ต้อง build และไม่ต้องเข้าสู่ระบบ

## เปิดงาน

1. ดาวน์โหลด ZIP เวอร์ชันปัจจุบัน แล้วเลือก Extract All / แตกไฟล์ทั้งหมด
2. เก็บโฟลเดอร์ไว้ในตำแหน่งที่คุณเขียนไฟล์ได้ เช่น Documents ชื่อโฟลเดอร์มีช่องว่างหรือภาษาไทยได้ ห้ามเปิด START.bat จากภายในหน้าต่าง ZIP โดยยังไม่แตกไฟล์
3. ภายในโฟลเดอร์เดียวกันต้องมี app, START.bat, STOP.bat, serve.py, manifest.json และคู่มือนี้
4. ดับเบิลคลิก START.bat ระบบจะตรวจไฟล์ เริ่มเซิร์ฟเวอร์เฉพาะในเครื่อง และเปิดเบราว์เซอร์เมื่อพร้อมแล้ว
5. ถ้าเบราว์เซอร์ไม่เปิด ให้เปิด Command Prompt ในโฟลเดอร์นี้แล้วรัน START.bat จากนั้นคัดลอก URL บรรทัด Ready หรือ Already running ไปเปิดด้วยตนเอง URL จะขึ้นต้นด้วย http://127.0.0.1: ตามด้วยหมายเลขพอร์ต

การเปิด START.bat ซ้ำจากโฟลเดอร์เดิมจะใช้เซิร์ฟเวอร์เดิม อาจเปิดแท็บใหม่ หากพอร์ตเริ่มต้น 8765 ถูกใช้อยู่ ระบบจะเลือกพอร์ตว่างอย่างปลอดภัยและไม่หยุดโปรแกรมอื่น แต่ละโฟลเดอร์ที่แตก ZIP แยกกันจะเป็นคนละชุดเซิร์ฟเวอร์

## ควบคุมระหว่างนำเสนอ

- Spacebar: ทำให้ภาพเคลื่อนไหวที่กำลังทำงานจบลงก่อน แล้วกดอีกครั้งเพื่อเปิดจังหวะถัดไปหรือเปลี่ยนฉาก
- R: ยกเลิกการเคลื่อนไหวและกลับหน้าปกเริ่มต้น
- ลูกศรซ้าย: กลับฉากก่อนหน้าในจังหวะสุดท้าย; F: เข้า/ออกเต็มจอ
- ใช้คำสั่ง Full screen ของเบราว์เซอร์ หรือ F11 บน Windows ตามการตั้งค่าแป้นพิมพ์ของคุณ
- จุดชี้บนพื้นที่งานใช้แทนเคอร์เซอร์เมื่อเลื่อนเมาส์ ไม่มีปุ่มนำทางบนภาพ และการคลิกไม่ใช่ขั้นตอนที่จำเป็น
- เมื่อนำเสนอ ให้คลิกพื้นที่งานหนึ่งครั้งเพื่อให้เบราว์เซอร์รับแป้นพิมพ์ แล้วใช้ Spacebar และ R

## หยุดและเปิดใหม่

1. ดับเบิลคลิก STOP.bat จากโฟลเดอร์เดียวกับที่เปิดงาน
2. เซิร์ฟเวอร์ของชุดนี้จะปิดอย่างเรียบร้อย แท็บเบราว์เซอร์อาจยังแสดงภาพที่โหลดแล้ว คุณปิดแท็บได้ตามปกติ
3. เปิด START.bat อีกครั้งเมื่อต้องการเริ่มใหม่

การปิดแท็บเบราว์เซอร์เพียงอย่างเดียวไม่หยุดเซิร์ฟเวอร์ STOP.bat ตรวจตัวตนและรหัสเฉพาะของเซิร์ฟเวอร์ก่อนสั่งหยุด ไม่ใช้การฆ่าโปรเซสตามพอร์ตหรือ PID อย่าลบ ย้าย หรือคัดลอกโฟลเดอร์ .local-server ระหว่างที่เซิร์ฟเวอร์ยังทำงาน และควรหยุดชุดเดิมก่อนแทนที่ด้วย ZIP เวอร์ชันใหม่

## ก่อนอัดหน้าจอ

- เข้า Full screen แล้วรอข้อความแจ้งเตือนของเบราว์เซอร์หายไปก่อนเริ่มอัด
- กด R เพื่อกลับหน้าปก ซ้อม Spacebar ให้ตรงกับบทบรรยายภาษาไทย
- ทดสอบความชัดของภาพและจุดชี้บนจอที่จะใช้อัดจริง
- เบราว์เซอร์และระบบปฏิบัติการอาจแสดงแถบหรือแจ้งเตือนของตนเอง แพ็กเกจไม่ปิดระบบรักษาความปลอดภัยให้

## ทดสอบบน Windows ของคุณ

รายการนี้ต้องตรวจบน Windows จริง การทดสอบ helper บน Linux ไม่ยืนยันผลของไฟล์ .bat

1. เปิด START.bat ตรวจหน้าปก จุดชี้ Full screen, Spacebar และ R
2. เปิด START.bat ซ้ำ ตรวจว่าใช้ URL เดิม
3. เปิด STOP.bat แล้วรีเฟรชแท็บเพื่อยืนยันว่าเซิร์ฟเวอร์หยุด จากนั้นเปิด START.bat ใหม่
4. หลังติดตั้ง Python แล้ว ให้ตัดอินเทอร์เน็ตและเปิดใหม่ ตรวจทุกฉาก ภาพ และตัวอักษร
5. จดเวอร์ชัน ZIP, SHA-256 ที่ผู้ส่งระบุ, รุ่น Windows/เบราว์เซอร์ และผลเปิด–หยุด–เปิดใหม่

## แก้ปัญหาเบื้องต้น

- พบ “Python 3.10 or newer was not found”: ติดตั้งหรือแก้ PATH ตามขั้นตอนเตรียมครั้งเดียว แล้วเปิดใหม่
- พบ “Integrity check failed”: อย่าแก้ manifest เพื่อข้ามการตรวจ ให้แตก ZIP ที่เชื่อถือได้ใหม่ทั้งชุด
- พบ “A different package version is running”: เปิด STOP.bat ของโฟลเดอร์นั้นก่อนเปิดเวอร์ชันใหม่
- พบ “Another start/stop is busy”: รอให้คำสั่งก่อนหน้าจบแล้วลองใหม่
- เปิดไม่ได้เพราะเขียนไฟล์ไม่ได้: แตก ZIP ไปโฟลเดอร์ในเครื่องที่คุณมีสิทธิ์เขียน ไม่ต้องรันเป็น Administrator
- ถ้าระบบหรือองค์กรบล็อก Python/ไฟล์ .bat ให้ติดต่อผู้ดูแลตามนโยบาย อย่าปิดไฟร์วอลล์หรือข้ามคำเตือนความปลอดภัย
- กรณีอื่น ให้ดูข้อความผิดพลาดในหน้าต่างคำสั่งและ .local-server/server.log ไฟล์ state.json มีรหัสควบคุมชั่วคราว ไม่ควรนำไปแชร์

## ขอบเขตความปลอดภัย

เซิร์ฟเวอร์ฟังเฉพาะ 127.0.0.1 ไม่เปิดให้เครื่องอื่นในเครือข่าย อ่านและให้บริการเฉพาะไฟล์ app ที่ผ่าน SHA-256 ใน manifest ไม่แสดงรายการโฟลเดอร์ ไม่ให้เปิดไฟล์ส่วนอื่นของเครื่อง ไม่รับ symlink/junction ในไฟล์แพ็กเกจ และเก็บเนื้อหาที่ตรวจแล้วไว้ในหน่วยความจำระหว่างการทำงาน

ไฟล์ manifest ใช้ตรวจความตรงกันของข้อมูล ไม่ใช่ลายเซ็นรับรองผู้สร้าง ให้ใช้ ZIP จากแหล่งที่เชื่อถือได้เท่านั้น ผู้ที่มีสิทธิ์แก้ไฟล์ทั้งหมดในบัญชีเดียวกันย่อมเปลี่ยนตัวโปรแกรมหรือรหัสชั่วคราวได้ คู่มือนี้จึงไม่อ้างว่าป้องกันผู้ดูแลเครื่องหรือมัลแวร์ในบัญชีเดียวกันได้
